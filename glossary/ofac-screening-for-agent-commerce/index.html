OFAC Agent Commerce Screening

Agent commerce screening applies sanctions checks to transactions an AI agent executes on its own.

TL;DR

TL;DR: OFAC agent commerce screening is the application of sanctions screening to autonomous commercial transactions executed by AI agents, so the agent verifies a counterparty before it pays.

What it means

An AI agent can buy services, pay invoices, and move funds without a human in the loop. Agent commerce screening inserts a sanctions check into that automated flow, comparing the counterparty against the SDN List before the payment fires. SanctionsAI makes this a single HTTP call that returns ALLOW or BLOCK in under 100 ms, so the check does not stall the agent.

Why agents need it

The payment rails agents use, including x402, AP2, ACP, and Coinbase AgentKit, move money but do not screen. That leaves a gap: the agent can pay a listed wallet because nothing stops it. Screening closes the gap before funds move, using 947 OFAC-listed crypto wallets and 19,218 SDN names so the agent inherits the same controls a human payment team would apply.

How the flow is structured

SanctionsAI frames this as the 4-Gate Agent Payment Protocol: SCREEN, SCORE, STOP, STAMP. The agent screens the counterparty, scores the risk, stops on a flag, and stamps the result. Because liability is strict, the screen has to run on every transaction, not just the risky looking ones. The result is a payment path where the agent can act fast and still meet the same screening standard a human would. Speed and compliance stop being in tension.
