OFAC UKRAINE-EO13661 sanctions program

UKRAINE-EO13661 is one of the program codes OFAC attaches to entries on the Specially Designated Nationals list. As of 2026-07-24 it appears on 196 SDN entries. Designations under this program are made under Executive Order 13661 (Ukraine), Executive Order 14024 (Russia) and Executive Order 13848 (Election).

What the UKRAINE-EO13661 code means on an SDN entry

OFAC does not maintain one list per sanctions program. It maintains one SDN list, and tags each entry with the program or programs it was designated under. An entry can carry several: of the 196 entries tagged UKRAINE-EO13661, 101 also carry at least one other program code.

The legal authorities OFAC records against these designations are:

  • Executive Order 13661 (Ukraine)
  • Executive Order 14024 (Russia)
  • Executive Order 13848 (Election)
  • Executive Order 13694 (Cyber)
  • Executive Order 13757 (Cyber)
  • Executive Order 13662 (Ukraine)
  • Executive Order 13660 (Ukraine)
  • Executive Order 13685 (Ukraine)
  • Executive Order 13382 (Non-proliferation)

That matters for screening: if you filter an SDN extract to a single program code you will silently drop entries that were designated under a different code but are blocked all the same. Screen the whole list, then use the program code to explain a hit — not to decide which entries to load.
