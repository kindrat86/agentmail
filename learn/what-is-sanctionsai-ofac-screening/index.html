What is SanctionsAI OFAC screening?

SanctionsAI is a free OFAC screening API that checks wallets, names, and countries in under 100 ms.

TL;DR

TL;DR: SanctionsAI is an OFAC screening API for developers and AI agents that returns ALLOW or BLOCK in one HTTP call under 100 ms.

What it does

SanctionsAI is an OFAC sanctions screening API for AI agents and developers. It screens a counterparty before the agent or application pays, returning a clean ALLOW or a flagged BLOCK decision in a single HTTP call that completes in under 100 ms. The design goal is simple: make screening fast enough to sit inside an automated payment flow.

What it checks

It checks live data drawn from the US Treasury SDN list, 19,218 names, plus 947 OFAC-listed crypto wallets across 16 jurisdictions, synced hourly. It applies the 50 Percent Rule, so entities owned 50% or more by a blocked person are treated as blocked. Beyond the core check, it exposes tools such as sanctions_check, risk_score, kya_verify, and dispute_open, organized around a four-gate protocol: SCREEN, SCORE, STOP, STAMP.

How to start

Getting started is low friction. There is a free tier of five checks per day with no signup and no key, paid tiers start at $19 per month, and an MCP server installs with pip install sanctions-mcp for Claude Code, Cursor, and other tools. It is MIT-licensed and self-hostable.

Pricing and the legal-fee guarantee

Pricing tiers are a free tier of five checks per day, a Dev tier at $19 per month, and a Pro tier at $99 per month, with per-check billing via x402 at $0.05. Paid plans include a $10,000 legal-fee guarantee. The code is MIT-licensed and self-hostable, so the data can also run on your own infrastructure.
