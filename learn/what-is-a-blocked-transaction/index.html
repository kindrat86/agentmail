What Is a Blocked Transaction?

Blocked transactions explained — the mechanism and the obligation after the block.

Overview

A blocked transaction is one that screening stops before settlement — the counterparty matches a sanctions list, so the payment cannot proceed.

What happens

  1. The screen returns a match (wallet_exact or name match)
  2. The payment is blocked and logged
  3. You review and document the block
  4. If it is a real hit, you report per OFAC obligations (blocking report within 10 days)

Why blocks are the product

A block is the firewall working — it converts a potential violation into a logged decision. The audit trail is the evidence.

The agent angle

An agent that hits a block should stop and surface the result — not retry endlessly. The retry scenario shows why.
