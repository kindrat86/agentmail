How Is the Sanctions List Synced?

How hourly list sync works - and why freshness is a compliance property.

TL;DR

TL;DR: The dataset syncs hourly from the official US Treasury SDN list - 947 wallets, 19,218 names, 16 jurisdictions, refreshed every hour.

The mechanism

Designations land between daily releases; hourly sync means a newly designated wallet is on the screen within the hour. The list version is recorded with every result.

Why freshness matters

Screen results are only as good as the list they ran against. A result logged against version N is provable; a screen that silently used a stale list is a compliance gap.

The agent angle

Agents run unattended - freshness is the difference between blocking a designation hours later and the moment it lands.
