How to handle an OFAC sanctions match

When your screening tool returns a sanctions match, follow these steps:
1. Block immediately. Do not process the transaction.
2. Preserve all records. Screenshots, logs, counterparty details, timestamps.
3. Alert your compliance contact. Someone needs to review within hours, not days.
4. File a blocked property report with OFAC within 10 business days if funds were blocked.
5. Consult counsel if the match is confirmed.
