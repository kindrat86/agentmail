Does agentmail Screen Names? [2026 Answer]

Yes, agentmail screens names, wallets, and countries against the OFAC SDN List before a payment proceeds.

TL;DR

TL;DR: Yes. agentmail screens names, wallet addresses, and countries against the OFAC SDN List, which holds 19,218 names and aliases, returning ALLOW or BLOCK in under 100 ms.

What name screening checks

agentmail compares a submitted name against the SDN List, the Specially Designated Nationals and Blocked Persons List. The match logic includes aliases and fuzzy matches, so a listed person transacting under a different spelling or a transliterated name is still flagged rather than slipping through on a spelling difference.

How it works in a payment

The check is a single HTTP call that runs before the agent pays. A clean counterparty returns ALLOW; a match returns BLOCK and the payment stops. This is the SCREEN step of the 4-Gate Agent Payment Protocol: SCREEN, SCORE, STOP, STAMP, which walks every agent payment through screening before any funds move.

Limits to know

A name is less precise than a wallet address, and common names can surface fuzzy matches for review. The risk_score tool helps triage those rather than treating every fuzzy hit as a hard block. For the strongest coverage, screen both the name and the wallet when both are available, since SanctionsAI also checks 947 OFAC-listed crypto wallets. Screening both fields together gives the strongest signal, since a wallet address alone would miss a listed person who has not yet been tied to an address. Using both means neither the name gap nor the wallet gap is left open.
