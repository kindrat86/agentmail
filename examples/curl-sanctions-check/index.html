Check OFAC sanctions with curl

The simplest way to test sanctions screening.

Check a wallet

curl "https://sanctionsai.dev/sanctions?wallet=0x098B716B8Aaf21512996dC57EB0615e2383E2f96"

Check a name

curl "https://sanctionsai.dev/sanctions?name=Oleg+Deripaska"

With jq pretty-print

curl -s "https://sanctionsai.dev/sanctions?wallet=0x..." | jq .

Batch check script

#!/bin/bash
for wallet in "0xabc..." "0xdef..."; do
    curl -s "https://sanctionsai.dev/sanctions?wallet=$wallet" | \
    grep -q 'blocked.*true' && echo "BLOCKED: $wallet"
done
