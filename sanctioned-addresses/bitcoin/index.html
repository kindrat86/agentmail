Why an address list is not a screening control

OFAC adds and removes addresses without notice, and a designated person can move funds to a fresh address at any time. There are three specific ways a static copy of this table fails in production:

  • It goes stale. The SDN list is republished on OFAC's schedule, not yours. The list this page was built from was published 2026-08-07.
  • It is chain-scoped. This page covers Bitcoin. A product that settles on several chains needs all 977 listings covering 961 unique addresses across every chain OFAC publishes, not one chain's worth.
  • It only catches exact addresses. The same designated persons are also blocked by name, and most sanctions exposure arrives as a counterparty name rather than an address already on the list.
